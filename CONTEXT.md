# Incubate Labs — domain language

Single source of truth for the brand's vocabulary. Site copy, marketing material, contracts, and any future spec must use these terms exactly. Aliases drift; this file picks one.

If two project docs disagree, this file wins. Fix the other place.

## The brand

| Term | Meaning | Don't say |
|---|---|---|
| **Incubate Labs** | The services brand. Capitalised, two words. Domain `incubatelabs.ai`. | "Incubate" alone (that's the methodology), "Incubator Labs", "iLabs". |
| **Incubate** | The methodology Incubate Labs uses to deliver engagements. Lower-case "the methodology" when used generically. | "the framework" (every consultancy has one; we have the methodology). |
| **Solo + agent-augmented** | The delivery model. One human practitioner using a custom skills framework outputs at small-team velocity. | "AI-powered consultancy" (lazy), "automated", "outsourced". |

## Methodology vocabulary

These are the methodology's own named concepts. Capitalisation matters; phase names are nouns, agent names are nouns.

| Term | Meaning |
|---|---|
| **Pattern** | One of the eight classifications an AI idea can match in the Frame phase. Drives data, risk, and infrastructure decisions. |
| **Phase** | One of the six methodology stages: Frame, Data, Pipeline, Build, Validate, Operate. |
| **Stage gate** | The named artefact that must exist before a phase advances. No artefact, no progress. |
| **Loopback** | Returning to an earlier phase because reality contradicted prior assumptions. A feature, not a regression. |
| **Project Record** | The growing artefact appended to by every agent across the engagement. Final deliverable. |
| **Agent** | A named role with defined inputs, tasks, and outputs: Scout, Surveyor, Forge, Architect, Auditor, Operator, plus cross-cutting Sponsor. |
| **Sponsor** | The cross-cutting agent that holds the commercial case and the stage-gate veto. Asks "should this still be happening?" at every handoff. |
| **Iteration** | One pass through one or more phases that ends with a delta — what was learned, what changed, what the next iteration should address. The unit of progress. |

## Engagement vocabulary

| Term | Meaning |
|---|---|
| **Engagement** | A paid piece of work. Either a packaged engagement (one of the three published) or a custom Incubate Engagement (flagship). |
| **Package** | A pre-priced, pre-scoped engagement: OSS Tool Hardening Pass / AI Governance Pack / Local-LLM Pilot. |
| **Free triage** | A 15–60-minute diagnostic call. Three formats: Local-AI Sovereignty Check / AI Session Audit / AI Pilot Scope Workshop. Real diagnostic work, not sales calls. |
| **Out of scope** | Explicit list of what a package does NOT cover. Every package detail page has one. |
| **Handover** | The end-of-engagement walkthrough call. Always included; not a separate add-on. |

## Voice & tone

- **Plain English.** UK gov style. Short sentences. No buzzword stacking.
- **Honest scope.** Every package names what's NOT in scope. Every free offering names what you bring and what you leave with.
- **Show, don't claim.** Every methodology principle should map to a public artefact (a repo, a live URL, a published process).
- **Data-sovereign by default.** Local-first, RAM-only, sub-processors named — these are convictions, not features.
- **Solo, not faceless.** First-person singular ("I") on the contact page; first-person plural ("we") when speaking as the brand.
